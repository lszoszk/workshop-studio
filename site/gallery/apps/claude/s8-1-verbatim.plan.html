The plan this app was built from · Claude Sonnet 5.5

Goal

A search tool for people drafting submissions, reports or briefs who need to find and cite exactly what a treaty body said in a General Comment. Type a search, find the real paragraph, copy a correct citation.

The data

WORKSHOP_DATA.gc, one record per paragraph. Fields used: text (searched and displayed), committee, year, symbol, paragraph, short_title, doc_url. title is used only when short_title is empty. id and cited_articles are not used.

What the app shows

  1. Title "General Comments search" and one line: source, number of paragraphs, year range, all read from the data.
  2. Search box with a Search button (Enter also searches) and a one-line help: words are combined with AND unless you write OR; NOT excludes a word; "quotes" find an exact phrase. Example: "best interests" AND child.
  3. Two filters: committee (every committee in the data, plus "All") and year (from–to). Changing a filter re-runs the search.
  4. A count line: "N paragraphs match out of M, filters: …".
  5. A small bar chart: matching paragraphs per committee for the current search, with a "How this is computed" note.
  6. Results, sorted newest General Comment first. Each card: committee, short title, year, the symbol linked to doc_url (new tab); then the full paragraph, with the search words highlighted; and a "Copy citation" button that copies the symbol and paragraph only, e.g. "CCPR/C/GC/37, para. 12". The button reads "Copied" for two seconds.
  7. If nothing matches: "No paragraph contains these words" and a tip to try OR or fewer words.

Rules for the code

  • The search looks at the paragraph text only. Matching is case-insensitive. A plain word matches a whole word ("right" does not match "rights"); a quoted phrase matches that exact sequence of words. Words separated by spaces are ANDed; OR joins alternatives; NOT before a word or phrase excludes it.
  • Filters are applied first, then the search. N, the chart bars and the cards come from the same list, so the bars add up to N.
  • text is shown character for character; highlighting only wraps the matched words and never changes, trims or summarises them.
  • The citation is symbol + ", para. " + paragraph, nothing invented.
  • Missing values: no short_title → show title, else the symbol; no year → show "year unknown", included when the year filter is open, excluded by a from–to range; no doc_url → symbol unlinked; empty text → never matches but still counted in M.

How we will know it works

  1. Search "best interests" AND child: every card highlights both "best interests" and "child"; the number of cards equals N.
  2. Search torture NOT detention: no card contains the word "detention".
  3. Choose CRC in the committee filter: the chart shows a single bar whose height equals N.
  4. Click Copy citation, paste into a text editor: you get the card's own symbol and paragraph, e.g. CRC/C/GC/14, para. 6.
  5. Click a symbol: the UN document opens in a new tab.

Not in this version

  • No brackets for grouping searches, no wildcards, no stemming ("right" and "rights" are different words).
  • No export of all results to a file.
  • No saved or shared searches.
