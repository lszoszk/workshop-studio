The plan this app was built from · Mistral Large 4

Goal

A checking tool for anyone who quotes a UN document paragraph by paragraph. It splits the raw PDF text of E/C.12/GC/27 into its numbered paragraphs and shows where the converter damaged the text, so the reader can verify the split before relying on it.

The data

WORKSHOP_DATA.pdf_text: title, symbol, doc_url and source for the heading and links; records (page, text) is the text to split; reference.paragraphs, reference.footnotes and reference.first_words are the answer key.

What the app shows

  1. Title and symbol linked to doc_url, with one line: "raw PDF text, N pages, source: …" (N from the data).
  2. Three counters: paragraphs found / paragraphs in the reference; footnotes removed / footnotes in the reference; paragraphs whose opening words differ from the reference. Under them: "Found by the code from the page text; reference figures come from the file."
  3. A table, one row per paragraph: number, page where it starts, first line (about 90 characters), symbol linked to doc_url, and a "Differs" mark where the opening words do not match. A tick box "Show differences first" moves marked rows to the top. Clicking a row opens the full paragraph beneath it, exactly as extracted, with the reference's first words shown beside it.
  4. A "Download CSV" button.
  5. A collapsed list "Lines removed as headers, footers and footnotes", so the reader can see nothing substantive was discarded.

Rules for the code

  • Join the pages in order. Remove lines that are only a page number, only the document symbol, or a distribution code ("GE." followed by digits).
  • Footnote lines (a small number then text, at the foot of a page) are removed from the paragraphs and only counted.
  • A paragraph starts where a line begins with the next expected number, a full stop and a space ("1. ", then "2. " …). Numbers out of sequence (years, cross-references) do not start a paragraph. Text runs until the next start.
  • Lettered sub-paragraphs stay inside their numbered paragraph.
  • "Differs" means the paragraph's first six words are not the reference's, comparing word by word while ignoring case, punctuation and extra spaces. If the reference has no entry for a number, show "no reference", not "Differs".
  • Paragraph text is never edited or paraphrased, only displayed.
  • The CSV holds number, page, whether it matches the reference, and the full text with values quoted, built and saved in the browser.

How we will know it works

  • The first counter reads "N of 90" (90 is the reference count in the file), with N close to it.
  • The table numbers run 1, 2, 3 … without gaps, and at least 30 rows appear.
  • Clicking row 1 shows text starting "A clean, healthy and sustainable environment".
  • Every row marked "Differs" shows the reference words it was compared with.
  • The downloaded CSV opens in a spreadsheet with as many rows as the table.

Not in this version

  • It flags damage; it does not repair text or reorder paragraphs.
  • Only this document; no upload of other PDFs.
  • No comparison with other language versions.
