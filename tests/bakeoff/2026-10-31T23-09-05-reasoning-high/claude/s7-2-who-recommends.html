How this is computed: only records whose mechanism is "Universal Periodic Review" and whose type is "Recommendations" are used. For each one, the code looks at the very end of the text (ignoring a final full stop) and reads the last bracketed expression, for example "…for all children (Croatia)." gives Croatia. Nested brackets such as "(Bolivia (Plurinational State of))" are handled. A bracket is accepted as a State only if it starts with a capital letter and is at most 60 characters long; otherwise the recommendation counts as "no State". If several States are named in one bracket, that bracket is counted as one name, exactly as written. This page uses all UPR recommendations and ignores the filters on the Dashboard tab. Nothing here is estimated by a model.
