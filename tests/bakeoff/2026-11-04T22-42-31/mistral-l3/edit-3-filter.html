This dashboard shows every paragraph from every UN document that carries a recommendation or observation on . The data comes from the Universal Human Rights Index (UHRI), built by OHCHR.

How each number is computed

The headline total is the count of all records in the file. The breakdown per type uses the values exactly as spelled in the data. Documents are the distinct document symbols. Years are the first and last year of records.

Filters: Mechanism, body, type: exact match on the field. Year: inclusive between the two selects. SDG: the record's SDG list includes the goal number. Keyword: every word must occur as a substring of the text or symbol (case-insensitive). The filtered set feeds the tiles, charts, table and export.

Theme counts: for each record in the filtered set, each value in its theme list counts once. Top ten by count, ties alphabetical. Percentage = count / filtered records, one decimal. Year range = min and max year of the filtered records carrying that theme.

Timeline: records per year per mechanism in the filtered set, with zero for missing combinations.

Paragraph number: the first match of /^(\d{1,3}(?:\.\d{1,3})?)\.?\s/ on the text; the captured group is the number. Recommending State: only for UPR; the trailing run of parenthesised groups, split and trimmed, accepted as a State if it has no comma and at most 60 characters.
