UN documents catalogue

? = the tool is not sure · file name or p.N = see the page text the value was read from

How this is computed: each value is read from the page text by a fixed pattern (a symbol such as LETTERS/…/…, a date such as "6 November 2025", the committee's name, "General comment No. N", the title lines that follow it, and sentences with "replaces" or "updates"). No model is asked, nothing is estimated, and a "?" marks every value where the pattern met a doubt.
