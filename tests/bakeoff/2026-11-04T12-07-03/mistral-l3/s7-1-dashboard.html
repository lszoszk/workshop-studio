How each number is computed

The dashboard counts, filters and sorts the records in the file with JavaScript. Every number is computed from the data, never estimated.

Headline total = number of records in the file. The breakdown counts records per type, using the values exactly as spelled in the data.

Documents = number of distinct document symbols. Years = minimum and maximum year in the file.

Filters. Mechanism, body, type: exact match on the field. Year: year inclusive between the two selects. SDG: the record's sdgs array includes the goal number. Keyword: every word must occur as a substring of text or symbol (case-insensitive).

Theme counts. For each record in the filtered set, each value in themes counts once. Top ten by count, ties alphabetical. Percentage = count / filtered records, one decimal. Year range = min and max year of the filtered records carrying that theme.

Timeline = records per year per mechanism in the filtered set, with zero for missing combinations.

Paragraph number = the first match of /^(\d{1,3}(?:\.\d{1,3})?)\.?\s/ on text. Recommending State = the trailing parenthesised groups in UPR texts, split and trimmed. Citation = symbol + ", para. " + paragraph number when one was found; otherwise symbol.
