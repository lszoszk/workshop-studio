HOW EACH NUMBER IS COMPUTED

The headline total is the count of all records in the file. The breakdown counts records per type, using the values exactly as spelled in the data.

Documents = number of distinct document symbols. Years = minimum and maximum year of the records.

Filters: Mechanism, body, type: exact match on the field. Year: the record's year is between the two selects. SDG: the record's SDGs include the goal number. Keyword: every word must occur as a substring of the text or symbol (case-insensitive).

Theme counts: for each record in the filtered set, each value in themes counts once. Top ten by count, ties alphabetical. Percentage = count / filtered records, one decimal. Year range = min and max year of the filtered records carrying that theme.

Timeline: records per year per mechanism in the filtered set, with zero for missing combinations.

Paragraph number: the first match of /^(\d{1,3}(?:\.\d{1,3})?)\.?\s/ on the text; the captured group is the number. Recommending State: only for UPR; the trailing run of parenthesised groups, split and trimmed. Citation: symbol + ", para. " + paragraph number when one was found; otherwise symbol alone.
