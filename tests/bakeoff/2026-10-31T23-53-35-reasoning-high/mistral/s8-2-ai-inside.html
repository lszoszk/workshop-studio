Overview of the dataset

How this is computed: each figure is a plain count over the records loaded in this page; mechanisms, bodies and years are the distinct values actually found in the data.

10 most frequent themes

How this is computed: each matching record adds 1 to every theme it carries (a record with three themes counts once in each of them); the 10 highest counts are charted. Exact counts, no estimates.

Suggest SDGs with AI

Clicking the button sends the first 50 records matching the current filters (or all of them if fewer match) — their full paragraph text — to an external language model, in batches of 25, and asks it to assign SDG numbers to each record. When you click, those texts leave this browser and are processed by the model behind this workshop's studio.ask API (the API does not disclose the model's name; if the model self-reports one, it is shown, marked AI). The model is not deterministic: running it again can give different answers. Everything the model returns is shown with an AI badge and is never mixed into the counts above.

Runs side by side

How this is computed: agreement rate = records where the model's SDG set exactly equals the UN's SDG set, divided by the records the model answered. The comparison itself is done exactly by this page, never estimated.
