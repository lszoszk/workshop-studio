AI SDG suggestions vs. the UN's own SDG tags

This tool sends the text of the first 50 records of the current selection (in batches of 25) to the workshop's external language model and asks it to assign SDG goal numbers to each paragraph. The result is then compared with the SDG tags already present in the UN data.

How this is computed: the model returns, for each record id, the SDG goal numbers (1–17) it would assign. "Agrees" means the set of AI goal numbers exactly matches the set of SDG numbers in the UN data for that record (records with no UN SDG tags agree only if the model also returns none). The agreement rate is the share of the 50 records where the sets match exactly — it is computed by this page, not by the model. Any run may fail to return valid JSON for some records; those are shown as "no answer".
