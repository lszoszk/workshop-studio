    METHOD

    How this was made, and take it with you

    How each number is computed

    Every number on this page is a count made by this page's own code over the records in the file; nothing is estimated and no language model is called.

    The filters work together: a record must pass every active filter. Inside one list, such as two bodies, any ticked value is enough. Selected themes must all be on the record. Every keyword (or "quoted phrase") must occur, ignoring capitals, in the text or the symbol; there are no synonyms.

    Theme bars count each theme once per matching record, so they add up to more than the records; percentages are of records, and the years come from the records carrying that theme. The timeline counts matching records per year and mechanism.

    The paragraph number is the number at the start of the text, if there is one. The recommending State is read from the closing parentheses of Universal Periodic Review texts only, and accepted if it has no comma and at most 60 characters; otherwise the record is shown as "State not found". The text itself is never changed.

    The date is the date of the document, not the date a recommendation was made or accepted, and the file does not say whether a recommendation was accepted or followed up.

    Themes, SDGs and affected persons are labels given by the UN database. This page never changes them; use 03 Check to judge them on a random sample.
