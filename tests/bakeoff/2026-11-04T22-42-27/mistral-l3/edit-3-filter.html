How each number is computed

Every number is computed from the data in this file, never estimated. The headline total is the number of records in the file. The breakdown counts records per type, using the values exactly as spelled in the data. Documents is the number of distinct document symbols. Years is the first and last year in the file.

Filters: Mechanism, body and document type match the field exactly. Year is inclusive between the two selects. SDG checks if the record's SDG list includes the goal number. Keyword matches every word as a substring of the text or symbol (case-insensitive). The filtered set feeds the tiles, charts, table and export.

Theme counts: for each record in the filtered set, each theme counts once. Top ten by count, ties alphabetical. Percentage is count divided by filtered records, one decimal. Year range is the first and last year of the records carrying that theme.

Timeline: records per year per mechanism in the filtered set, with zero for missing combinations.

Paragraph number: the first match of a number at the start of the text (e.g. "71." or "144.43."). Recommending State: only for UPR; the text's trailing parenthesised groups, split and trimmed. Citation: symbol and paragraph number when found, otherwise symbol alone.
