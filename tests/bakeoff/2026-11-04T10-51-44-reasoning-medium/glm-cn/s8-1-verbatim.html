HOW THIS IS COMPUTED
  • Matching runs over each paragraph's normalised text: footnote marks removed, curly quotes and dashes made straight, whitespace collapsed, lower case — so a phrase pasted from Word still matches.
  • A word matches whole words only; a trailing star allows any ending. A hyphen is a word boundary, so state finds non-State.
  • Hits are the records whose Boolean tree is true and that pass the committee, year and document filters.
  • The citation is built only from the record's fields: symbol, pinpoint (para. N, preamble, or subpara. (b)), and, when a symbol holds several General Comments, the committee and document name first. Nothing is invented or corrected.
  • The copied quotation is the stored text with footnote marks removed and its own leading number dropped; the draft keeps the text as stored as well.
  • Counting, matching, sorting and highlighting are done by this page's code; no model is called and nothing leaves the browser.
